Политика конфиденциальности

Приложение: MarketShorts. Обновлено 27 октября 2026 года.

MarketShorts — персональное приложение, которое использует YouTube Data API v3 и TikTok Content Posting API для публикации видео в собственный канал и собственный аккаунт TikTok своего владельца. Политика описывает, какие данные приложение получает и как с ними обращается.

1. Какие данные запрашиваются

При авторизации через Google приложение запрашивает два разрешения:

  • https://www.googleapis.com/auth/youtube.upload — загрузка видео в канал владельца;
  • https://www.googleapis.com/auth/youtube.readonly — чтение статуса и метаданных собственных видео канала.

При авторизации через TikTok приложение запрашивает три разрешения:

  • user.info.basic — имя и аватар авторизованного аккаунта;
  • video.publish — публикация готового видео в аккаунт владельца;
  • video.upload — загрузка черновика видео в инбокс аккаунта владельца.

Приложение не запрашивает доступ к Gmail, контактам, Google Диску, календарю, аналитике других каналов и любым другим данным аккаунта Google. Со стороны TikTok приложение не запрашивает личные сообщения, список подписок, аналитику и данные других аккаунтов.

2. Какие данные обрабатываются

Приложение работает с: названием и идентификатором собственного канала и собственного аккаунта TikTok (display name, open_id), метаданными загруженных видео (идентификатор, статус обработки, видимость) и OAuth-токенами доступа. Иных персональных данных приложение не собирает.

3. Где хранятся данные

Все данные хранятся локально на компьютере владельца: OAuth-токены — в локальном файле с ограниченными правами доступа, метаданные публикаций — в локальной базе данных. Данные не передаются на сторонние серверы, не публикуются и не используются для рекламы.

4. Передача третьим лицам

Приложение не передаёт данные третьим лицам. Внешние системы, с которыми взаимодействует приложение, — сервисы Google (YouTube Data API) и сервисы TikTok (TikTok Content Posting API), и только в объёме, необходимом для загрузки и публикации видео.

5. Срок хранения и удаление

Токены и метаданные хранятся до момента отзыва доступа или удаления локальных файлов приложения. Отозвать доступ к Google можно в любой момент на странице myaccount.google.com/permissions, к TikTok — в разделе Security and permissions настроек аккаунта TikTok; после отзыва приложение теряет возможность обращаться к аккаунту.

6. Безопасность

Файлы с токенами доступны только локальному пользователю, не попадают в системы контроля версий и не передаются по сети, кроме запросов к API Google по защищённому соединению.

7. Дети

Приложение не предназначено для использования детьми и не собирает данные о них.

8. Изменения политики

Актуальная версия политики всегда доступна по этому адресу. Дата обновления указана в начале страницы.

MarketShorts

Личный инструмент для подготовки и публикации коротких вертикальных видео в собственный YouTube-канал и собственный аккаунт TikTok.

Что делает приложение. По ссылке на товар собирает открытые данные о нём, генерирует вертикальный ролик с озвучкой и субтитрами и публикует готовое видео через официальные API платформ.

Куда публикует. В YouTube-канал владельца через YouTube Data API v3 и в аккаунт TikTok владельца через TikTok Content Posting API. Никакие другие аккаунты не затрагиваются.

Кто использует. Один человек — владелец канала, владелец аккаунта TikTok и владелец этого приложения. Приложение не предназначено для третьих лиц, не публикуется в магазинах приложений и не предоставляет доступ другим пользователям.

Доступ к данным YouTube. Запрашиваются только youtube.upload (загрузка видео) и youtube.readonly (проверка статуса собственных загруженных видео). Почта, контакты, файлы на Диске и любые другие данные Google не запрашиваются.

Доступ к данным TikTok. Запрашиваются user.info.basic (имя и аватар авторизованного аккаунта), video.publish (публикация готового видео) и video.upload (загрузка черновика в инбокс авторизованного аккаунта). Личные сообщения, подписки и другие данные TikTok не запрашиваются.

Как это работает

  • Владелец запускает сборку ролика на своём компьютере и указывает ссылку на товар.
  • Приложение собирает видео: вертикальный кадр 1080×1920, озвучка, вшитые субтитры, музыка.
  • Владелец авторизует свой аккаунт TikTok по OAuth и подтверждает публикацию.
  • Видео уходит в аккаунт владельца: прямой публикацией или черновиком в инбокс — на выбор владельца.
